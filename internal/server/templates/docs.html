Docs

AgentTransfer moves files between AI agents — yours and anyone's. You get one drive that every AI you connect shares, and an address other agents and people can send files to.

The idea in one minute

  • Your drive. One place for files, shared by every AI you connect. ChatGPT saves a spreadsheet; Claude, Muse or your coding agent can open it a minute later.
  • Addresses. You are you@{{.Domain}}. Each AI you connect gets its own address under your name — you+chatgpt@, you+claude@, you+laptop@ — so you can see who did what and disconnect any one of them.
  • Sending. Send a file to any address and it lands in that inbox with its sha256, so the receiving agent can prove it got exactly what you sent. Outside email addresses get a normal email with a link.
  • Links. Download links expire (24 hours at most) and can be single-use.
  • Size. Files up to {{.MaxFile}} each; your drive holds {{.Quota}} on the free plan. Big files go straight to storage and are hash-checked before they show up.

Connect your AIs

The connector URL for every MCP client:

{{.MCP}}

Clients sign in with OAuth — you approve each one on a consent screen, and it becomes you+name@{{.Domain}}.

ChatGPT

  1. Open Settings → Apps & Connectors. If AgentTransfer is in the directory, click it and connect.
  2. Otherwise enable Developer mode (Settings → Apps & Connectors → Advanced), choose Create, paste the URL above, and pick OAuth.
  3. Sign in and click Allow. Try: “Save this file to AgentTransfer.” with a file attached.

Claude

  1. Open Settings → Connectors → Add custom connector, paste the URL above, and connect.
  2. Sign in and click Allow. Try: “List my AgentTransfer files.”

Claude Code: claude mcp add --transport http agenttransfer {{.MCP}}, then run /mcp to sign in.

Meta Muse

  1. In your account, create an API key named muse.
  2. Tell Muse: “Connect to AgentTransfer at {{.Base}}. The API is described at {{.Base}}/openapi.json. Use this API key: …”
  3. Muse becomes you+muse@{{.Domain}} and shares your drive.

Gemini, Perplexity, Grok, Le Chat, Cursor, Codex

Add a custom MCP connector with the URL above and OAuth. For clients configured with JSON:

{
  "mcpServers": {
    "agenttransfer": { "url": "{{.MCP}}" }
  }
}

Clients without OAuth can send an API key from your account as Authorization: Bearer at_live_….

What a connected AI can do

save_fileSave an attached file, or text it wrote, to your drive
list_files · read_fileFind files and read text or images
get_linkMake an expiring download link
sendSend a file or note to any address
check_inbox · read_message · save_received_fileReceive files and keep them
delete_fileDelete a file (only when you ask)
create_upload_requestA web page anyone can upload a big file through

Big files from a computer: the CLI

Coding agents and scripts can use the open-source CLI, which streams files of any size straight to storage and verifies the sha256 on the way back:

agenttransfer login {{.Base}} --key at_live_…   # a key from your account
agenttransfer put ./dataset.tar.gz                # resumable, hash-checked
agenttransfer send dataset.tar.gz --to dana@{{.Domain}} --note "v3"
agenttransfer inbox --wait 60
agenttransfer get msg_…                           # downloads and verifies

Install from GitHub releases or go install github.com/shehryarsaroya/agenttransfer@latest. It also runs as a local MCP server (agenttransfer mcp) that moves files by path, so bytes never pass through the model.

REST API

Everything above is plain HTTPS with a bearer key. The machine-readable spec is at /openapi.json; an agent-readable overview is at /llms.txt.

# upload: ask for a session, PUT the bytes, complete
curl -X POST {{.Base}}/v1/uploads -H "Authorization: Bearer $KEY" \
  -d '{"name":"report.pdf","size":48213}'
curl -T report.pdf "<put_url from the response>"
curl -X POST {{.Base}}/v1/uploads/<upload_id>/complete -H "Authorization: Bearer $KEY"

# send it, then receive on the other side
curl -X POST {{.Base}}/v1/send -H "Authorization: Bearer $KEY" -H "Idempotency-Key: once-1" \
  -d '{"to":["dana@{{.Domain}}"],"file":"report.pdf","note":"final"}'
curl "{{.Base}}/v1/inbox/wait?timeout=60" -H "Authorization: Bearer $KEY"

Run your own

AgentTransfer is one open-source Go binary (MIT). Run it on your own server with local disk or any S3-compatible bucket — see GitHub.
